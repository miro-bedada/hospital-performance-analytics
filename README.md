# Data visualization and AI for hospital performance analytics and forecasting



## Project Overview

This project explores how data visualization and artificial intelligence can support hospital performance analytics and forecasting. It focuses on key hospital indicators to better understand patient demand, hospital capacity, and healthcare service utilization.

## Key Performance Indicators (KPIs)

The analysis focuses on the following indicators:

- **OPD Attendance:** Number of outpatient visits.
- **IPD Admissions:** Number of inpatient admissions.
- **Discharges:** Number of patients discharged.
- **Emergency Visits:** Number of emergency visits.
- **Bed Availability:** Number of available beds.
- **Bed Occupancy Rate (BOR):** Measures how intensively hospital beds are used.
- **Average Length of Stay (ALOS):** Average duration of inpatient care.

## Project Objectives

- Explore hospital performance data using exploratory data analysis (EDA).
- Visualize trends and patterns in hospital activity.
- Analyze relationships between hospital performance indicators.
- Prepare data for predictive modeling.
- Evaluate forecasting models to support hospital planning and decision-making.

## How to Run

Open the notebook in [Google Colab](https://colab.research.google.com/) or Jupyter Notebook and run the cells sequentially.

## Expected Outcome

This project aims to demonstrate how data analytics, visualization, and forecasting can help monitor hospital performance, anticipate healthcare service demand, and support evidence-based operational planning.
